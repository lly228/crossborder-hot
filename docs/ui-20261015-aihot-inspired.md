# 跨境HOT整体界面方案

日期：2026年10月15日
范围：精选、全部、热点榜、收藏、主题、日报、周报、月报及移动端。
设计判读：这是给跨境卖家快速判断经营影响的资讯工作台，采用克制的编辑排版。用户先看事件，再看来源、影响和建议动作。用户明确要求模仿新版aihot.news，因此界面采用其浅色侧栏、青绿识别色、日期时间线和卡片层级；跨境HOT字标、跨境电商分类及行业内容继续使用本项目自己的内容。

### 令牌调整边界

本次改版已在`:root`中调整背景、文字和强调色，在`[data-theme=dark]`中覆盖全部背景、文字、边界及语义令牌。组件规则继续引用令牌。时间轴节点、字标前圆点和选中导航共用`--color-accent`及`--color-accent-subtle`；中档评分专用`--color-warning`，高档评分专用`--color-success`，避免青绿导航改变评分原有含义。新增的`--color-warning-subtle`与`--color-text-on-accent`也集中在主题令牌中。新版模仿aihot.news的识别色，同时保留跨境HOT的名称和跨境电商内容，这是改变旧版橙色品牌取值的原因。

设计令牌目标关系：`--color-bg-primary`作为页面画布，`--color-bg-secondary`作为侧栏和日期区底，`--color-bg-tertiary`作为搜索框与悬停底，`--color-bg-elevated`作为新闻卡与浮层；四层在明暗两套主题里都能被辨认。`--color-text-secondary`承载摘要，不能降到占位文字的灰度。评分数字如使用语义色作小字，另加较深的文字用色令牌并核对对比度，避免沿用现有浅色语义色导致低于4.5:1。禁用态仍须保留可读性。

## 2．方向与信息层级

产品UI采用`frontend-design`作为审美主线。

| 四问 | 结论 |
| --- | --- |
| Purpose | 卖家每天用几分钟判断哪些平台、合规、物流变化影响经营，并决定先读哪条原文 |
| Tone | 编辑部资料台。近白纸面、无衬线标题、细时间轴和青绿识别点，保持专业资讯感 |
| Constraints | 纯静态、无构建、`file://`可用；现有筛选和事件聚合语义不变；键盘、触屏、浅深主题均可用 |
| Differentiation | 等宽窄时间列旁连续出现的青绿事件节点，以及每条新闻内可快速扫到的卖家影响与建议动作 |

| 审美项 | 决策与理由 |
| --- | --- |
| 字体 | 本版以无衬线显示标题、日期和正文，以等宽字体显示时间、排名和评分。密集信息用字重及间距区分层级 |
| 配色 | 青绿承担跨境HOT字标圆点、导航、时间轴及主要操作，橙色只表示65至74分及提醒，绿色表示75分及以上。近白与浅灰绿背景建立层级 |
| 运动 | 首次加载仅让前6条资讯以短距离、短时差进入；筛选只做区域淡入，避免每次搜索都让整页重新跳动 |
| 空间 | 桌面采用固定窄侧栏与宽信息列，卡片高度随内容变化；时间轴打破卡片纵向重复，保留清楚的浏览顺序 |
| 背景细节 | 纸面式细分隔与连续时间线形成背景纹理，不增加噪点或装饰图，避免干扰密集信息阅读 |

| 层级 | 元素 | 视觉权重 |
| --- | --- | --- |
| 第一层 | 当前视图标题、每条资讯标题；精选首页的最新重要事件标题 | `--text-2xl`与`--text-lg`，600至800字重，`--color-text-primary`；标题高于标签和评分 |
| 第二层 | 日期、事实摘要、卖家影响、建议动作、分类筛选与搜索 | `--text-xl`或`--text-base`；摘要用`--color-text-secondary`，动作标签用品牌强调色但正文保持主文字色 |
| 第三层 | 时间、信源、信源类型、评分、原始来源、鲜度、收藏与页脚 | `--text-sm`至`--text-xs`；时间用等宽，次要文字用`--color-text-muted`，风险或停更另配文字与图标 |

为什么：原页面已经把时间和评分放在边缘，用户真正要读的是事件标题及经营影响。扩大主标题与卡片间距即可加强判断顺序，不需要大面积数据数字。

## 3．布局结构

已实施桌面布局将`.app-shell`最大宽度设为1480px，侧栏230px，主列左右各52px内距；1000px以下侧栏缩为190px、主列内距30px。1440px屏上信息列明显宽于侧栏。`aside.sidebar`固定在视口内，内容滚动发生在页面本身；侧栏过长时应允许自身滚动，不截断主题。

```text
宽屏
┌────────侧栏230px────────┬────────────主内容列────────────┐
│ 跨境HOT / 内容 / 报告 / 主题 │ 顶栏：日期·鲜度       搜索·主题 │
│ 当前项用青绿图标与浅底标记   │ 标题与说明                       │
│ 底部：主题切换与开源链接     │ 分类筛选·只看未读               │
│                              │ 重要事件摘要卡，仅精选默认态显示 │
│                              │ 日期栏                           │
│                              │ 等宽时间列·轴线│资讯卡│收藏 │
└──────────────────────────────┴────────────────────────────────┘
```

桌面顶栏保持搜索常驻。分类筛选紧随视图标题与说明，与只看未读按钮同处工具栏；全部六类同屏尽量完整。精选默认态先放最新重要事件摘要，再进入日期时间线。摘要卡采用一列紧凑编号列表，最多5条。新闻卡以来源及分类、标题、事实摘要、推荐理由、卖家影响、建议动作、相关信源的顺序展开，空字段不留空行。热点榜为独立有序单列，可显示排名和热度。

时间信息继续占卡片左侧窄列，时间数字使用`--font-mono`。日期栏改为无衬线加粗，显示星期与当日条数；它已取消粘性，以免遮盖顶栏。线从日期栏下方连接同一天的青绿事件节点，不穿过文字。卡片在时间线右侧，节点位于卡片外缘；节点和线只提供视觉顺序，日期与时间仍以文本呈现。

报告视图继续使用现有`.mag`的刊头、导语、目录、按分类分区、统计和跨报告入口。侧栏、顶栏、搜索、分类筛选与主题颜色跟信息流一致；报告正文不改成资讯卡。热点榜已采用有序单列，每行包含排名、标题、摘要、来源和热度。

响应式采用375、760、1000、1440px作为验收宽度。1000px以下先缩窄双栏；760px以下隐藏侧栏，顶栏保留品牌、鲜度、搜索和主题按钮，`.mobile-nav`提供可横向滑动的视图导航；分类标签单独横向滚动。移动端主列左右留`--space-4`，精选摘要卡、资讯卡全宽单列，时间列压窄但仍在左侧。375px时需核对顶栏空间及搜索框宽度，任何宽度不得产生页面级横向滚动。

为什么：用户要求模仿新版aihot.news的设计方法，项目原有页面也已采用左侧导航加时间线主列。扩大桌面阅读区、加入青绿节点后，跨境电商事件仍是主角；移动端切成单列可保持顺序。

## 5．交互与动效

视图与分类切换后，当前导航、标题、列表和空态同步更新。过渡为列表内容向上移动不超过一个`--space-2`并淡入，时长`--duration-normal`，缓动`--easing-default`。用户连续输入搜索词时不执行整列逐项动画，避免持续闪动。初次加载最多前6张卡按40至60ms间隔进入；其余直接呈现。悬停与按下状态使用`--duration-fast`。主题切换使用`--duration-normal`，只过渡背景、文字和边界色；不用全屏闪白。减少动态效果偏好下全部静止，内容仍完整可见。

本地收藏与主题设置应立即反馈，失败时就近出现清楚的文字提示。资讯源链接维持新标签打开；从日报翻天和跨视图跳转回退时，当前导航状态应可预测。筛选或关键词造成空结果时保留搜索条件，空态提供清除筛选入口。数据脚本缺失或解析失败时显示数据暂不可用与刷新建议；不要用永远转动的加载图标遮住旧内容。数据鲜度来自`window.NEWS_META`，继续保留现有24小时与72小时阈值。

信息可访问性底线：正文与背景对比度不低于4.5:1，大字不低于3:1；小字号彩色评分须单独核对；键盘聚焦环明确；状态不能只靠色彩；移动端可点目标44px；标题在375px宽度避免单字孤行；日期线与节点不覆盖卡片文字；不添加无图例的图表。本次没有表单提交，搜索输入仍需可见名称；若以后增加订阅表单，应在字段附近显示错误与必填信息。

## 6．现有DOM与样式改造顺序

1. `index.html`已保留`.app-shell`、`.sidebar`、`.main`、`.topbar`、`.feed-head`、`#hotspots`、`#feed`和`#emptyState`，并在侧栏底部与移动端顶栏加入主题切换入口；两个按钮应始终显示同一主题状态。
2. `assets/app.js`继续以`CATEGORIES`、`TOPICS`、`VIEWS`和`selected`驱动界面。`selected`决定精选；`score`只决定影响强度色阶。精选折叠同一`eventId`，全部保留原始条目。不要为卡片布局改变数据schema。
3. `renderTimeline`已给日期区补当天条数，卡片使用装饰性伪元素绘制时间轴节点；节点不由屏幕阅读器重复播报。`renderRow`保留标题与信源的真实链接、收藏及已有信息字段，并增加已读状态。
4. `assets/style.css`中的`:root`与`[data-theme=dark]`仍是唯一颜色取值入口。当前样式已加入浅深主题、青绿节点、卡片和热点榜；后续整理应收拢重复旧规则，避免相同选择器前后覆盖造成维护困难。
5. `assets/app.js`已接入主题记忆、未读筛选、热点榜和分页加载。继续核对桌面与移动端主题按钮同步、60条追加后的日期条数，以及各视图筛选组合下的空态。

## 7．自检与待决策项

反套路检查：无衬线标题、青绿识别点、独立橙色评分与等宽时间列组合成跨境HOT的资讯界面；没有紫色渐变、玻璃卡、三等分大屏或无关装饰。首页用摘要卡和连续时间轴组织信息。去色后，标题、摘要、时间和动作仍按字号、字重与位置区分。缩小到60％时，侧栏与主列的视觉重心平衡；按钮与标签共用同一规则；全页以青绿为主、橙色只承担评分及提醒语义。

已定取舍：品牌识别色已从旧版橙色改为青绿。原因是用户明确要求模仿新版aihot.news，同时保留跨境HOT字标与跨境电商行业内容。65至74分独立使用`--color-warning`橙色；日期栏已改无衬线，时间继续使用等宽字体。

待决策项：

1. 项目当前`--font-body`是系统中文字体栈，`frontend-design`建议避免系统字体；中文字体补丁又建议系统栈优先。此版沿用项目现状以保证零加载和`file://`可用。若未来要求跨平台完全一致，再单独决定是否自托管思源黑体子集。
2. 当前浅色主画布已改为近白，深色令牌也已加入；仍需核对两套主题中小字号评分、弱化文字、按钮禁用态的实际对比度。
3. 移动端资讯标题和摘要当前分别为14px、12px，低于工程底线规定的移动端正文16px；触控目标也有28px至30px的旧规则。实施仍需调整这些值，并在375px宽度复核不横向滚动。
